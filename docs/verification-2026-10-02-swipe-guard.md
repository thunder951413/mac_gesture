# 2026-10-02 悬停掌缘与三指滑动误触修复

环境：Apple Silicon Mac，高级触控板模式。基线为提交 `918745e`，包含上一轮的接触尺寸掌缘过滤。

## 近期记录

安装上一轮修复后，原应用日志仍记录以下“三指下滑关闭窗口”的实际规则触发和动作完成（本机时间，UTC+8）：21:29:47、22:36:25、22:44:21、22:44:24、22:59:00。22:36:25 和 22:59:00 附近都有两指滚动后出现三指判定的记录。用户确认近期没有有意执行三指下划。

这里统计的是 `[Rule]` 及 `[Action]`，不是“没有匹配的启用规则”的普通识别观察。原日志对识别结果按 200 ms 节流，动作前最后一次显示的距离可能低于配置阈值，不能据此认定匹配忽略了阈值。旧日志没有保存原始触点，因此不能还原上述每次触发的完整轨迹。

## 新采样复现

独立 QA 副本采用和用户相同的触发条件：只配置三指向下规则，向下位移至少 `0.08`，动作仅追加测试日志。特别保留两指滚动未匹配的行为；为两指也配置动作会提前消费手势，掩盖滚动中途被升级为三指的问题。

本轮原始采样中，一段 481 帧、约 3.83 秒的输入只含两个真正接触并滚动的手指，另一个顶部边缘触点持续处于状态 `2`（`hoverInRange`）约 3.6 秒。其椭圆约 7.9×5.2，与指尖相近，上一轮仅按接触尺寸排除掌缘的方案无法过滤它。

将完全相同的输入按原规则回放：

| 识别器 | 三指向下动作尝试 |
| --- | --- |
| 基线 `918745e` | 1 次，`dx=-0.00328`，`dy=-0.08586`，满足 `0.08` 关窗阈值 |
| 本轮修复 | 0 次，最多使用两个有效手指 |

原始触点状态顺序参考 [Hammerspoon 的 MultitouchSupport 接口定义](https://github.com/asmagill/hs._asm.undocumented.touchdevice/blob/master/MultitouchSupport.h)：状态 `3/4` 为接触，状态 `2` 为悬停，`5/6/7` 为离开过程。实际采样符合这一含义。该复现证明了一种仍存在的误触路径；不将缺少原始帧的五次历史事件都归因于同一种路径。

## 修复行为

- 掌缘尺寸过滤之后，只将状态 `3/4` 计入手指组；悬停和离开状态不参与中心点及位移计算。触点帧也校验状态范围 `0...7`。
- 三指及以上滑动按每根手指相对起点的位移检查共同平移。每根手指在中心点运动方向上的位移需达到中位数的一半及最低滑动距离的一半，且横向偏离不超过前向位移。静止、明显滞后或反向移动的第三触点不能触发多指滑动。
- 只保留满足共同平移的滑动峰值，实时触发与抬起后的判定使用同一证据，避免抬手路径绕过检查。正常滑动后回缩或部分抬指仍使用已确认的峰值。
- 两指手势持续至少 80 ms 且已经移动 `0.03` 后固定原手指组，中途新接触不能把未匹配的两指滚动升级为三指。初始错开落指和抬手后的新手势仍可使用三指。
- 四指及五指捏合/张开在共同平移检查之前按形变识别，支持拇指相对固定。
- 每次实际规则入队记录未经观察节流的 `[GestureMatch]` 距离、`dx/dy`，同时保存短段原始触点、判断结果和起止位置。

## 后续定位

普通日志位于 `~/Library/Logs/Gesture/gesture.log`。新触点诊断位于 `~/Library/Logs/Gesture/touch-traces.jsonl` 及 `touch-traces.old.jsonl`，包含规则入队或防误触判断之前的短段输入。正常两指滚动不会连续落盘；独立 QA 配置的触点日志写在该配置旁的 `diagnostics` 目录。

完整现场采样、基线及新版本回放输出、原生应用动作日志保留在本机忽略的 `.build/runtime-qa/`。纳入仓库的夹具只含相对时间和触点数据。
